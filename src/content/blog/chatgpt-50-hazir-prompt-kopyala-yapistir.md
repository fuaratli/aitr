ChatGPT'den iyi çıktı almak %20 model, %80 prompt. Aşağıda **5 ana kategoride 50 prompt şablonu** var. Hepsi denenmiş, Türkçe yazılmış, ve `[KÖŞELİ PARANTEZ]` içindeki kısımları kendi durumuna uyarlayarak kullanabilirsin.

> 💡 **İpucu:** Bu prompt'ları "Custom GPT" veya "Project" içine kaydedersen sürekli erişebilirsin.

## 💼 İş ve Profesyonel Yazım (1-10)

### 1. Profesyonel E-posta Yazma
```
Şu konuda profesyonel bir e-posta yaz: [KONU].
Alıcı: [ALICI - örn. "müşteri", "müdür", "tedarikçi"]
Ton: [TON - örn. "kibar ama net", "samimi", "resmi"]
Hedef: [Ne yapmalarını istiyorsun]
Maksimum 150 kelime, Türkçe.
```

### 2. Toplantı Özeti Çıkarma
```
Aşağıdaki toplantı notlarını şu formatta özetle:
1. Ana kararlar
2. Aksiyon maddeleri (kim, ne, ne zaman)
3. Açık kalan sorular
4. Bir sonraki adım

Notlar:
[NOTLARI YAPIŞTIR]
```

### 3. Sunum Yapısı Hazırlama
```
[KONU] hakkında 15 dakikalık bir sunum hazırlayacağım. 
Hedef kitle: [KİME SUNUYORSUN]
Amacım: [SUNUM SONUNDA NE OLMASINI İSTİYORSUN]

10 slaytlık bir yapı öner. Her slaytın başlığı + 3 ana noktası olsun.
```

### 4. İş Teklifi Reddetme
```
Bir iş teklifini kibarca reddetmem gerekiyor.
Pozisyon: [POZİSYON]
Sebep (özetle): [SEBEP]
Köprüleri sağlam bırakacak, gelecekte tekrar görüşmeye açık bir reddetme yaz.
```

### 5. Zam Talep Etme E-postası
```
Müdürüme zam talep eden bir e-posta yazmam gerek.
Pozisyonum: [POZİSYON]
Süre: [Şirkette ne kadardır çalışıyorsun]
Başarılarım: [3-4 somut başarı]
İstediğim artış: [Yüzde/miktar]

Verimliliğimi gösteren, somut sayılarla destekli ama saygılı bir e-posta yaz.
```

### 6. LinkedIn Post'u
```
LinkedIn için viral potansiyelli bir post yaz.
Konu: [KONU - örn. "yapay zekanın işime etkisi"]
Tonum: [Düşünür, eğitici, kişisel hikaye, vs.]
Format: İlk satır kanca, 5-6 kısa paragraf, son satır soru.
Türkçe, 200-250 kelime.
```

### 7. Müşteri Şikâyetine Cevap
```
Aşağıdaki müşteri şikâyetine profesyonel cevap yaz:
[ŞİKAYET METNİ]

Cevapta:
- Empati göster
- Sorumluluğu kabul et
- Çözüm öner (alternatifli)
- Marka itibarını koru
```

### 8. CV Özet Bölümü
```
Aşağıdaki bilgilerle güçlü bir "Hakkımda / Özet" bölümü yaz (CV başı için):
İsim: [İSİM]
Pozisyon: [HEDEF POZİSYON]
Deneyim: [YIL]
Uzmanlık alanları: [3-4 alan]
Önemli başarı: [BİR ÖNEMLİ BAŞARI]

3-4 cümle, etki odaklı.
```

### 9. Mülakat Sorularına Cevap Hazırlama
```
[POZİSYON] için mülakatım var. "[MÜLAKAT SORUSU]" sorusuna güçlü bir cevap hazırla.

Geçmiş deneyimim: [DENEYİM ÖZETİ]
Cevap STAR formatında olsun (Situation, Task, Action, Result).
```

### 10. Sözleşme Maddesi Anlama
```
Aşağıdaki sözleşme maddesini sade Türkçe ile açıkla. Hukuki bir kişi değilim, ne anlama geldiğini ve dikkat etmem gereken noktaları söyle.

Madde:
[MADDE METNİ]
```

## ✍️ Yaratıcı Yazım (11-20)

### 11. Blog Yazısı Yapısı
```
"[BAŞLIK]" konusunda 1500 kelimelik blog yazısı yapısı oluştur.
Hedef anahtar kelime: [ANAHTAR KELİME]
Tonu: [Resmi/samimi/eğitici]
SEO için H2 başlıkları ve her birinin altında 3-4 alt nokta.
```

### 12. Hikaye Üretme (Roman Açılışı)
```
[TÜR — örn. polisiye, bilimkurgu, dram] türünde bir hikaye açılışı yaz.
Mekan: [MEKAN]
Ana karakter: [KISA AÇIKLAMA]
Açılış cümlesi okuyucuyu yakalasın.
500 kelime, Türkçe.
```

### 13. Şiir Yazma
```
Şu konuda bir şiir yaz: [KONU]
Stil: [Modern/lirik/serbest/Karacaoğlan tarzı]
Uzunluk: [Dörtlük/8 satır/kısa]
Türkçe.
```

### 14. Sosyal Medya Hashtag'leri
```
[KONU/SEKTÖR] için Instagram'da kullanılacak 20 hashtag öner.
- 5 popüler
- 10 orta seviye
- 5 niş
Türkçe ve İngilizce karışık.
```

### 15. Slogan Üretme
```
[ÜRÜN/HİZMET] için 10 slogan öner.
Marka kimliği: [Genç/lüks/güvenilir/eğlenceli]
Kısa, akılda kalıcı, Türkçe.
```

### 16. YouTube Video Başlığı
```
"[KONU]" hakkında yapacağım YouTube videosu için 10 tıklanma garantili başlık öner.
Hedef kitle: [HEDEF KİTLE]
Stil: [Eğitici/hikaye/şok edici]
CTR optimize.
```

### 17. Etkili E-kitap Özeti
```
Aşağıdaki konuda 10 sayfalık bir e-kitap için içindekiler ve her bölüm için 2-3 cümle açıklama oluştur.

Konu: [KONU]
Hedef okuyucu: [KİME YAZIYORSUN]
Ana vaadi: [E-KİTAP SONUNDA OKUYUCU NE ELDE EDECEK]
```

### 18. Düğün/Doğum Günü Konuşması
```
[DURUM - örn. en yakın arkadaşımın düğünü] için 3 dakikalık konuşma yaz.
Konuşmacı: [KİMSİN, ne ilişkin]
Anı paylaşmam isteniyor: [BİR HATIRA]
Gözyaşı + mizah dengesi olsun, Türkçe.
```

### 19. Tweet İpliği (Thread)
```
"[KONU]" hakkında 10 tweet'lik X/Twitter ipliği yaz.
İlk tweet kanca olsun.
Her tweet 280 karakter altında.
Son tweet'te çağrı veya soru olsun.
```

### 20. Tanıtım Metni
```
[ÜRÜN/HİZMET] için landing page satış metni yaz.
Sorun: [HEDEF KİTLE NE ACI ÇEKİYOR]
Çözüm: [ÜRÜN NASIL ÇÖZÜYOR]
3 fayda noktası, sosyal kanıt yeri, CTA. AIDA formatı.
```

## 💻 Yazılım ve Kod (21-30)

### 21. Kod Açıklama
```
Aşağıdaki kodu satır satır açıkla. Ben yeni başlayan bir geliştiriciyim:

[KOD]
```

### 22. Hata Ayıklama
```
Aşağıdaki kodu çalıştırdığımda şu hatayı alıyorum:
Hata: [HATA MESAJI]

Kod:
[KOD]

Sorunu açıkla ve düzeltilmiş kodu ver.
```

### 23. Refactor (Kod İyileştirme)
```
Aşağıdaki kodu daha okunabilir ve verimli hale getir.
Dil: [PROGRAMLAMA DİLİ]
Hedef: [Performans / okunabilirlik / her ikisi]

[KOD]

Değişiklikleri yorum olarak belirt.
```

### 24. SQL Sorgusu Yazma
```
Şu tablo yapısı var:
[TABLO ŞEMASI]

İstediğim sorgu: [DOĞAL DİLDE İSTEK]

PostgreSQL/MySQL/SQLite (hangisi) için optimize SQL yaz.
```

### 25. API İsteği Örneği
```
[API ADI] için Python ile [İŞLEM] yapan örnek bir kod yaz.
Hata yönetimi olsun.
.env dosyasından API key okusun.
```

### 26. Unit Test Yazma
```
Aşağıdaki fonksiyon için unit test yaz.
Dil: [Python/JS/Go]
Framework: [pytest/Jest/testing]

[FONKSIYON KODU]

En az 5 farklı senaryo: normal, edge case'ler, hata.
```

### 27. README Oluşturma
```
Bir GitHub projesi için README yaz.
Proje: [PROJE ADI ve KISACA NE YAPIYOR]
Teknolojiler: [LISTELE]
Kurulum gereksinimleri: [LISTELE]

Bölümler: Açıklama, Özellikler, Kurulum, Kullanım, Katkı, Lisans.
```

### 28. Database Şema Tasarımı
```
[UYGULAMA TÜRÜ] için veritabanı şeması tasarla.

Gereksinimler:
- [GEREKSİNİM 1]
- [GEREKSİNİM 2]
- ...

Tablolar, ilişkiler, indeksler. PostgreSQL.
```

### 29. Regex (Düzenli İfade) Oluşturma
```

Dil: [Python/JS/Go]
Örnek inputlar:
- [ÖRNEK 1]
- [ÖRNEK 2]

Regex'i açıkla ve test örnekleri ver.
```

### 30. Mikroservis Mimarisi
```
[UYGULAMA AÇIKLAMASI] için mikroservis mimarisi öner.

Beklenen yük: [KULLANICI SAYISI/TPS]

Hangi servisler, hangi iletişim (REST/gRPC/Queue), hangi DB, hangi cloud servisleri.
```

## 🧠 Eğitim ve Kişisel Gelişim (31-40)

### 31. Konu Öğretme (Karmaşık Konu Basit)
```
"[KONU]" konusunu bana 5 yaşındaki bir çocuğa anlatır gibi açıkla. Sonra 15 yaşına, sonra üniversite seviyesine. Aşamalı.
```

### 32. Çalışma Planı Oluşturma
```
[SINAV/HEDEF] için çalışma planı oluştur.
Süre: [KAÇ HAFTA/AY]
Günde ayırabileceğim süre: [SAAT]
Mevcut seviyem: [BAŞLANGIÇ/ORTA/İLERİ]

Haftalık plan + günlük detay. Türkçe.
```

### 33. Kitap Özeti
```
"[KİTAP ADI - YAZAR]" kitabını oku ve şu formatta özetle:
- 3 cümle özet
- 5 ana fikir
- Hayata nasıl uygulanır (somut adımlar)
- En çarpıcı 3 alıntı
```

### 34. Dil Öğrenme Pratik
```
[YENİ DİL — örn. İngilizce/Almanca] öğreniyorum, seviyem [A1/A2/B1/B2/C1].

"[KONU]" hakkında 10 cümlelik pratik yap:
- Cümleyi hedef dilde yaz
- Türkçe çevirisini ver
- Yeni kelimeleri listele

Sonunda bana 3 soru sor, cevaplayayım.
```

### 35. Eleştirel Düşünme — Tartışma
```
"[İDDİA]" iddiasını analiz et.

Şu yapıda:
1. İddianın güçlü argümanları (3 madde)
2. Karşı argümanlar (3 madde)
3. Mantıksal hatalar varsa belirt
4. Senin objektif değerlendirmen
```

### 36. Karar Verme Yardımı (Pros/Cons)
```
İki seçenek arasında kararsızım:
A) [SEÇENEK A]
B) [SEÇENEK B]

Bağlam: [SENİN DURUMUN]
Öncelikleriniz: [3 ÖNCELİK]

Her ikisinin artıları, eksileri ve hangisinin sana uygun olduğuna dair tavsiye ver.
```

### 37. Spor/Egzersiz Programı
```
[HEDEF — örn. kilo verme, kas yapma, koşu maratonu] için 4 haftalık antrenman programı oluştur.

Seviyem: [BAŞLANGIÇ/ORTA/İLERİ]
Haftalık antrenman sayım: [GÜN]
Erişimim: [Ev / spor salonu / her ikisi]
Yaralanmalar: [VARSA]

Egzersizler, set/tekrar, ısınma/soğuma dahil.
```

### 38. Yemek Tarifi Önerisi
```
Akşam yemeği için tarif öner.
Buzdolabımda: [MALZEME LİSTESİ]
Süre: [DAKIKA]
Zorluk: [Kolay/orta]

Adım adım tarif, malzeme miktarı dahil.
```

### 39. Borç/Bütçe Yönetimi
```
Aylık gelirim: [GELİR]
Aylık zorunlu giderlerim: [TOPLAM]
Borçlarım: [LISTE]
Hedefim: [TASARRUF/BORÇ KAPATMA]
```

### 40. Motivasyon Hayat Tavsiyesi

## Promtpları Nasıl Daha İyi Kullanırsın?

### 1. Bağlam ver
ChatGPT senin kim olduğunu, ne için kullandığını bilmiyor. Her prompt'a 1-2 cümle bağlam ekle.

### 2. Örnek ver
İstediğin çıktının formatına dair örnek verirsen kalite 2x artar.

### 3. Aşamalı sor
Karmaşık şeyleri tek prompt'la çözmek yerine, ilk cevabı al, sonra "bunu şöyle değiştir" diye iterasyon yap.

### 4. Custom GPTs kullan
Sürekli aynı prompt'u yazıyorsan, ChatGPT'de Custom GPT oluştur (Plus üyelikte). Kalıcı talimatlarla başlasın.

### 5. Sistem mesajı (talimat) ekle
"Sen bir Türk SEO uzmanısın" gibi rol tanımları çok işe yarar.

Bu 50 prompt'u yer imi yap, lazım olunca kopyala. İlk hafta hepsini denemen gerekmiyor — sana uygun 10 tanesini bulup hayatına entegre et.
